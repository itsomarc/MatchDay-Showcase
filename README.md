# ⚽ MatchDay — Football Team Management

A mobile application designed to simplify football team management, communication, and match preparation.

Built as an independent software development project targeting both iOS and Android.

## 📱 Project Overview

MatchDay aims to provide football clubs, coaches, and players with a centralized platform for managing their teams.

The project started as a local mobile application and is evolving into a secure, database-backed, multi-user platform.

## ✨ Features

- Player and squad management
- Interactive drag-and-drop lineup builder
- Starting XI and bench management
- Match scheduling
- Player availability tracking
- Match results and goalscorer tracking
- User authentication
- Role-based access control
- Multi-team management in development

## 🏗️ Backend Architecture

The application is transitioning from local storage to a centralized backend architecture.

Current development includes:

- Firebase authentication and token verification
- PostgreSQL database schemas
- Backend API endpoints
- Database migrations
- Role-based permissions
- Secure database access
- Automated integration testing
- Revision-checked data updates

## 🔐 Security

Security is an important part of the development process.

The project explores authenticated API requests, restricted database permissions, server-side authorization, and separation between users, teams, and clubs.
